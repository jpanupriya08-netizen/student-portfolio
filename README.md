# Student Developer Portfolio

A responsive student portfolio built with React, Vite, Material UI, and React Router.

## Run locally

```bash
npm install
npm run dev
```

Create and check a production build with `npm run build`, then preview it with `npm run preview`.

## What's included

- Home, About, Skills, Projects, project detail, and Contact pages
- Responsive navigation and page layouts
- Three starter project concepts based on the supplied portfolio brief
- Vercel rewrite configuration for React Router routes

## Before submitting

Replace the sample project concepts with your own work. Update the display name and portfolio copy, add your real project links and social profiles, and connect the contact form to an email service if you want it to deliver messages. The current form is a front-end demo and does not send email.
